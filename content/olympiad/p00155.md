<div class="mp" id="p00155">
    <p><a class="mpl" href="/olympiad/p00155/">Problem 00155</a></p>
    <p>Find all the elements of the set $\left\{\left\lfloor\frac{3}{2x}\right\rfloor \mathrel{\Big|} x \in \mathbb{R} \text{ and } \frac{1}{\lfloor x\rfloor} + \frac{1}{\{x\}}=2x \right\}$.</p>
    <details>
        <summary>Hint</summary>
        <p>Try substitutions based on the identity $x=\lfloor x\rfloor+\{x\}$.</p>
    </details>
    <details>
        <summary>Solution</summary>
        <p>To avoid division by zero, $x \neq 0$, $\lfloor x\rfloor \neq 0$, and $\{x\} \neq 0$. The equation becomes:</p>
        <p class="mpc">
            \[ \frac{\lfloor x\rfloor+\{x\}}{\lfloor x\rfloor\{x\}} = 2x \implies \frac{x}{\lfloor x\rfloor\{x\}} = 2x \implies x(2\lfloor x\rfloor\{x\}-1)=0 \]
        </p>
        <p>Since $x \neq 0$, we have $\{x\} = \frac{1}{2\lfloor x\rfloor}$. Let $\lfloor x\rfloor=n \in \mathbb{Z}$. Because $0<\{x\}<1$, we must have $n\ge1$.</p>
        <p class="mpc">
            \[ x = n + \frac{1}{2n} = \frac{2n^2+1}{2n} \]
        </p>
        <p>The term defining the set becomes $\left\lfloor\frac{3}{2x}\right\rfloor = \left\lfloor\frac{3n}{2n^2+1}\right\rfloor$. For $n=1$, this equals $1$. For $n>1$, $0 < \frac{3n}{2n^2+1} < 1$, so its floor is $0$. The set is exactly $\{0,1\}$.</p>
    </details>
